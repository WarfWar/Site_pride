# Кафе «Прайд» — сайт и Android-приложение

Актуальный адаптивный сайт кафе «Прайд» в Волновахе создан на основе исходников Android-приложения.

## Возможности сайта
- Меню: 108 позиций кухни и 108 бара с фотографиями и ценами.
- Корзина с сохранением выбранного, поиск, категории и свежие новости Telegram.
- Интерактивная схема зала с выбором столика, датой, временем и числом гостей.
- Подготовка текста заявки и звонок для подтверждения: +7 (949) 068-48-88.

**Важно:** девять столов в интерфейсе — предварительная демонстрационная схема, а не настоящая планировка кафе. Занятость онлайн не проверяется. Выбор столика не создаёт подтверждённое бронирование; заказчик должен связаться с администратором.

## Исходники
- android/app/src/main/assets/site/ — актуальный интерфейс и фотографии Android-приложения.
- website/build_site.py — сборка сайта из Android-ресурсов и актуальной Telegram-ленты.
- website/booking.js и website/booking.css — интерфейс выбора столика.
- .github/workflows/pages.yml — публикация сайта через GitHub Pages при каждом изменении main.
- .github/workflows/pride-news.yml — синхронизация публичных новостей.

## Локальный запуск
1. Запустите: python3 website/build_site.py
2. Затем: cd _site && python3 -m http.server 8000
3. Откройте http://localhost:8000

## Настоящее бронирование
Для бронирования без звонка потребуется схема зала, часы работы и база занятости столов с панелью администратора.

## Публикация
GitHub → Settings → Pages → Source: GitHub Actions. Workflow: Publish Pride Cafe site.
