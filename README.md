# Кафе «Прайд» — сайт-меню

Статический адаптивный сайт кафе «Прайд» (Волноваха, ул. Ленина, 108).

## Что в проекте
- 125 пунктов кухни, восстановленных из сохранённого текста опубликованной версии меню.
- Поиск по блюдам, фильтр категорий, переключатель кухни/бара.
- Все графические элементы этой версии находятся локально в `assets/*.svg` и не требуют внешнего фотохостинга.
- Телефон: +7 (949) 068-48-88.
- Статический HTML, CSS, JS, JSON: сборка и сервер не нужны.

## Локальный запуск
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000. Через `file://` загрузка JSON через fetch может блокироваться браузером.

## Публикация
GitHub → Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save.

## Важно
Это **воссозданная версия** сайта по сохранённому тексту, а не точная выгрузка исходного проекта ChatGPT Site. Оригинальные бинарные изображения опубликованного сайта не доступны для экспорта, поэтому вместо них используются локальные SVG-иллюстрации. Меню бара в доступном тексте не было — цены напитков не придуманы. Для замены на оригинальные фотографии положите файлы в `assets/` и обновите ссылки в HTML.
