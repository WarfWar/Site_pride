# Прайд — Android-приложение

Android 7.0+ (API 24), офлайн-приложение с оригинальным оформлением сайта кафе «Прайд».

## Возможности
- 125 блюд в 15 разделах из `../data/menu.json`.
- Поиск, фильтры категорий, описания и цены.
- Корзина «Мой выбор»: добавить блюдо, увеличить/уменьшить количество, удалить, очистить.
- Сохранение выбора через `localStorage` после закрытия приложения.
- Предварительная сумма только для блюд с однозначной числовой ценой; позиции с неизвестной/вариативной ценой обозначаются отдельно.
- Все пять SVG-иллюстраций и меню находятся **в APK**, поэтому меню и корзина работают без сети.
- Ссылки на звонок и карту открываются через установленные приложения Android.
- **Нет оформления заказа, оплаты, передачи заказов кафе или учётных записей.** Это персональный список.

## Технологии
Минимальная Android-оболочка на Java с `androidx.webkit:webkit` и `WebViewAssetLoader`. Сайт упакован в `app/src/main/assets/site`, с отдельной корзиной `cart.js` / `cart.css`. Сайт в корне GitHub остаётся нетронутым.

## Сборка APK
Откройте в Android Studio папку `android` как проект.
Или запустите `gradle -p android assembleDebug` с JDK 17, Gradle 8.9 и Android SDK 35.
Путь к APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions → **Build Pride Android APK** → последний успешный запуск → Artifacts → **PrideCafe-debug-apk**.

## Меню
Меню скопировано из текущего сайта на момент выпуска. Смена цен в интернете автоматически APK не обновляет: при изменениях требуется новая сборка. Если нужно регулярно синхронизировать данные, можно добавить обновления в следующих версиях.

## Примечание
Первая версия для проверки на физическом Android-устройстве. Публикация в Google Play и релизная подпись APK не настроены.

## Фотографии карточек (v1.1.0)
Каждая карточка меню и каждая позиция в корзине показывает иллюстративную фотографию блюда. Фотографии выбираются по категории/ключевым словам из `assets/site/photos.js`. Это **не оригинальные фотографии готовых блюд кафе**, реальная подача может отличаться. Источник фотографий — Unsplash, лицензия: https://unsplash.com/license; информация об изображениях в `photo-sources.json`.

GitHub Actions скачивает и проверяет фотографии перед сборкой APK, затем упаковывает их внутрь приложения, чтобы карточки работали **офлайн**. Для локальной сборки сначала выполните:
```bash
python3 android/scripts/fetch_photos.py
```
Если снимок недоступен, карточка показывает локальную SVG-иллюстрацию; сборка CI останавливается, если скачано меньше 12 фото.

## Оригинальные фотографии сайта (v1.2.0)

В Android-версию восстановлены **именно 125 файлов изображений кухни** с опубликованного оригинального сайта кафе «Прайд»: https://cafe-pride-menu.savory-heron-9771.chatgpt.site/ . Порядок фотографий взят из исходного `/menu.json`, а не подобран по категориям. Меню Android содержит соответствующее поле `image` для каждого блюда.

Чтобы загрузить исходные фотографии локально перед первой сборкой: `python3 android/scripts/fetch_original_photos.py`. В CI этот шаг обязателен. Скрипт проверяет фактический формат WebP и наличие всех 125 изображений. Сборка содержит эти снимки офлайн. Если оригинальный сайт когда-нибудь перестанет открываться, сохранённые файлы можно использовать повторно; workflow также пытается закоммитить их в GitHub и сохраняет отдельным артефактом.

Указанные изображения соответствуют опубликованному сайту, а не обязательно реальному виду порций в кафе.


## v1.4.0 — Новости Telegram и фирменная маркировка
Оригинальный логотип со львами пользователя хранится локально в `assets/pride-original-logo.png`. Каждое изображение блюда в меню и корзине имеет ненавязчивую маркировку «Фото для знакомства — ваше блюдо может выглядеть иначе».

Публичные новости загружаются с `https://t.me/s/cafe_Pride_Volna` сервером GitHub Actions раз в час и публикуются в `data/news.json`. Приложение читает JSON из публичного репозитория и кэширует последние новости для офлайн-просмотра. Никакой вход в Telegram, токены или закрытые группы не нужны. Источник и время сообщения показаны в интерфейсе; каждую публикацию можно открыть в Telegram.

APK теперь собирается только штатным Gradle/Android SDK и проверяется Android build tools `apksigner verify`. Старый вручную перепакованный APK 1.3 был некорректен. Если новое приложение не устанавливается поверх предыдущего, удалите старую версию (при этом личный список выбранных блюд может быть потерян) и установите новый APK.
